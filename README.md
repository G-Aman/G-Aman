### ⚡ Architecture & Focus

<details open>
<summary><b>🌐 Edge Networking & Systems</b></summary>
<br>

- **Overlay Topologies:** Multi-site WireGuard meshes interconnecting heterogeneous cloud nodes and on-prem hardware.
- **Embedded Routing:** Custom OpenWrt builds with CoovaChilli + RADIUS captive portal controllers.
- **Traffic Shaping & Filtering:** Hardware NAT offloading, VLAN isolation, and DNS sinkholing via AdGuard and Unbound.
- **Server Hardening:** Debian server lifecycle management, kernel tuning, iptables rulesets, and SSH bastion access.

</details>

<details>
<summary><b>🏠 IoT & Home Automation</b></summary>
<br>

- **Custom Integrations:** Authored native Home Assistant HACS components via hardware protocol reverse-engineering.
- **Smart Infrastructure:** Sensor automation pipelines, local network telemetry, and multi-protocol device coordination.

</details>

<details>
<summary><b>☁️ Cloud Infrastructure & Proxies</b></summary>
<br>

- **Edge Ingress:** Caddy and Nginx reverse proxies with automated zero-touch TLS, HTTP/3, and strict security headers.
- **Compute Clusters:** Linux VPS instances orchestrated with declarative container stacks and automated snapshot backups.

</details>
